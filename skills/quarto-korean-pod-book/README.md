# Quarto Korean POD Book

한국어 Quarto 원고를 **교정 가능한 소스 → A5 POD 내지 → 펼침표지 → EPUB → 최종 검수 자료**로 완성하기 위한 Codex 스킬입니다.

단순히 PDF를 한 번 출력하는 도구가 아닙니다. 책의 내용과 근거를 먼저 검토하고, 인쇄 사양을 확정한 뒤, 조판·표지·전자책·검수·Git 인계까지 하나의 재현 가능한 작업 흐름으로 관리합니다.

## 주요 기능

- 한국어 장문 원고의 목차·장 구조·중복 논지 점검
- 수치와 주장에 대한 출처·단위·기준일·사실/추정/전망 구분
- A5 내지의 한글 글꼴, 행간, 표, 각주, 고아줄·과부줄 점검
- PDF와 EPUB의 동시 제작 및 산출물 분리
- 실제 쪽수와 종이 두께에 따른 책등·날개 펼침표지 계산
- 종이책/전자책 ISBN, 정가, 발행처, 바코드의 불일치 방지
- 차트의 흑백 인쇄 가독성과 삽화의 일관된 아트 디렉션 점검
- 독립 레드팀 검수와 GitHub 인계 기록 작성

## 설치

### 1. 저장소 전체를 받은 뒤 복사

```bash
git clone https://github.com/waterfirst/Debate-on-Semiconductor-Technology-and-the-Humanities.git
mkdir -p ~/.codex/skills
cp -R Debate-on-Semiconductor-Technology-and-the-Humanities/skills/quarto-korean-pod-book \
  ~/.codex/skills/
```

업데이트를 계속 받으려면 복사 대신 심볼릭 링크를 사용할 수 있습니다.

```bash
ln -s "$(pwd)/Debate-on-Semiconductor-Technology-and-the-Humanities/skills/quarto-korean-pod-book" \
  ~/.codex/skills/quarto-korean-pod-book
```

### 2. 필요한 실행 환경

- [Quarto](https://quarto.org/)
- Python 3
- PDF 조판용 TeX 배포판: [TinyTeX](https://quarto.org/docs/output-formats/pdf-engine.html#installing-tex) 또는 TeX Live
- 프로젝트가 지정한 한국어 글꼴

현재 개발 환경에서는 Quarto 1.9.38과 Python 3.12에서 점검했습니다. 실제 POD 제출 규격은 이용할 인쇄소나 유통 플랫폼의 최신 안내를 우선합니다.

## 빠른 시작

책 프로젝트 폴더에서 Codex를 실행하고 다음처럼 요청합니다.

```text
$quarto-korean-pod-book 스킬을 사용해 이 Quarto 원고를 점검해줘.
먼저 현재 목차, 출판 메타데이터, 미확정 항목과 위험 요소를 보고하고
내 승인 전에는 ISBN·정가·쪽수·책등을 추정해서 확정하지 마라.
```

기존 책을 출간 후보본으로 만드는 예시:

```text
$quarto-korean-pod-book 스킬로 한국어 A5 POD 출간 후보본을 만들어줘.
본문을 교정하고 근거를 검증한 뒤 PDF와 EPUB을 렌더해라.
최종 쪽수로 책등을 다시 계산하고, 대표 페이지를 이미지로 검수한 뒤
남은 인쇄소 의존 항목을 별도로 보고해라.
```

## 한국 1인 출판 전체 로드맵

아래 순서는 대한민국에서 자신의 출판사명으로 종이책과 전자책을 출간·판매하는 경우를 기준으로 합니다. 개인저자 자격으로 교보문고의 출판 브랜드를 이용하는 경우에는 출판사 신고·발행자번호 신청을 생략할 수 있지만, **자기 출판사명과 ISBN으로 계속 출간하려면 출판사 사업자 절차를 밟는 편이 적합합니다.**

법령, 세무 기준과 플랫폼 계약은 바뀔 수 있습니다. 신청 직전에는 연결된 공식 안내와 관할 시·군·구, 국세청 또는 세무대리인에게 다시 확인하세요.

### 0. 출판 방식과 권리관계 결정

- [ ] 개인저자로 1권만 낼지, 자기 출판사명으로 계속 발행할지 결정합니다.
- [ ] 종이책 POD, 전자책, 직접 판매, 외부 서점 유통 범위를 정합니다.
- [ ] 상호·출판사명·도메인·SNS 계정의 기존 사용 여부를 검색합니다.
- [ ] 공동저자, 삽화가, 교정자와 저작권 귀속·사용 범위·보수·2차 이용을 서면으로 정합니다.
- [ ] 글꼴, 이미지, 도표, 인용문, AI 생성물의 출처와 상업적 이용 조건을 기록합니다.

저작권은 창작과 동시에 발생하며 등록이 출판의 필수조건은 아닙니다. 다만 권리관계를 공시하거나 분쟁 시 추정력을 얻을 필요가 있으면 [한국저작권위원회 저작권 등록](https://www.copyright.or.kr/business/registration/index.do)을 검토할 수 있습니다. 출판사명이나 로고를 장기적으로 사용할 계획이면 상표 출원도 별도 검토합니다.

### 1. 사업장과 출판사명 준비

- [ ] 실제 사용할 사업장 주소를 확정합니다.
- [ ] 임차 장소이면 임대차계약서와 해당 장소의 사업자등록 가능 여부를 확인합니다.
- [ ] 공동주택이나 공유오피스이면 관리규약·임대계약·관할 지자체의 출판사 신고 가능 여부를 먼저 확인합니다.
- [ ] 출판사명, 대표자, 소재지 표기를 모든 신청서에서 동일하게 사용합니다.

### 2. 관할 시·군·구에 출판사 신고

- [ ] [정부24 출판사 (변경)신고](https://www.gov.kr/mw/AA020InfoCappView.do?CappBizCD=13700000045&HighCtgCD=A07002&tp_seq=) 또는 관할 시·군·구청에서 신고합니다.
- [ ] 임차 사업장은 임대차계약서 등 정부24가 안내하는 구비서류를 준비합니다.
- [ ] **출판사 신고확인증**의 출판사명·대표자·주소를 확인합니다.
- [ ] 신청 수수료와 별개로 관할 지자체가 고지하는 **등록면허세**가 있으면 납부하고 영수증을 보관합니다.

출판사를 경영하려는 자는 영업 전에 관할 지자체에 신고해야 합니다. 출판사명이나 소재지 등 신고사항이 바뀌면 변경신고 대상인지 확인해야 하며, 정부24는 변경일부터 20일 이내 신고를 안내합니다.

### 3. 홈택스 사업자등록 또는 기존 사업자 업종 정정

- [ ] 신규 사업자는 사업 개시 전 또는 개시일부터 20일 이내에 홈택스나 세무서에서 신청합니다.
- [ ] 기존 개인사업자가 있으면 새 사업자를 중복 개설하기 전에 **일반 서적 출판업** 등 실제 업무에 맞는 업종을 추가할지 검토합니다.
- [ ] 출판사 신고확인증, 임대차계약서, 신분증 등 신청 화면이 요구하는 증빙을 준비합니다.
- [ ] 종이책·요건을 충족하는 전자출판물 판매가 부가가치세 면세라는 점과, 교육·광고·상품 판매 등 과세 업종이 함께 있는지를 구분합니다.
- [ ] 사업자등록증의 상호, 사업장, 업태·종목과 과세유형을 확인합니다.

국세청은 사업자등록을 사업장마다 하며 사업 개시 전에도 신청할 수 있다고 안내합니다. 도서 공급은 원칙적으로 부가가치세 면세지만, 책과 무관한 과세 매출이 함께 있으면 면세·과세 겸업 관리가 필요합니다.

### 4. 사업용 결제·장부·증빙 체계 만들기

- [ ] 사업용으로 사용할 계좌와 카드를 정하고 개인 생활비와 분리합니다.
- [ ] 홈택스에 사업용 신용카드를 등록하고 현금 결제에는 지출증빙용 현금영수증을 받습니다.
- [ ] 출판사 신고비, 등록면허세, 교정·디자인·인쇄·소프트웨어·광고·배송비를 일자별로 기록합니다.
- [ ] 계약서, 견적서, 카드전표, 계산서·세금계산서, 계좌이체 내역을 거래별로 연결합니다.
- [ ] 책별로 제작비, 판매량, 반품, 정산액과 손익을 구분합니다.
- [ ] 외주자에게 보수를 지급하면 소득 구분, 원천징수와 지급명세서 의무를 지급 전에 확인합니다.

국세청은 개인사업자의 장부와 증빙 보관을 요구합니다. 한 장부에서 도서 면세매출과 다른 과세매출이 섞이지 않도록 매출·공통경비를 구분하세요.

### 5. 국립중앙도서관 발행자번호 신청

- [ ] [국립중앙도서관 ISBN·ISSN·UCI·납본 시스템](https://www.nl.go.kr/seoji/)에 발행자로 가입합니다.
- [ ] 출판사 신고확인증 등 신청에 필요한 발행자 정보를 제출합니다.
- [ ] **발행자번호가 배정된 뒤** 개별 도서 ISBN 단계로 넘어갑니다.
- [ ] 발행자번호와 계정정보는 내부 기록으로 관리하고 원고 메타데이터와 혼동하지 않습니다.

발행자번호는 출판사를 식별하는 번호이고 개별 책의 ISBN이 아닙니다. 인쇄사나 단순 출판대행사는 발행자를 대신해 임의로 ISBN을 신청할 수 없습니다.

### 6. 책 메타데이터와 판본 확정

- [ ] 도서명·부제·저자·옮긴이·발행처를 확정합니다.
- [ ] 판차, 종이책/전자책 구분, 판형, 예상 쪽수, 정가, 발행예정일을 정합니다.
- [ ] 독자층, 주제분류, 한국십진분류(KDC), 키워드와 책 소개를 준비합니다.
- [ ] 종이책과 전자책을 각각 발행하면 서로 다른 ISBN을 사용할 계획을 세웁니다.
- [ ] 단순 재쇄인지 내용이 바뀐 개정판인지 구분하고 새 ISBN 필요 여부를 확인합니다.

ISBN 신청값, 판권면, 표지, 유통사 상품정보가 서로 다르면 승인·정산·납본 과정에서 문제가 생길 수 있으므로 하나의 메타데이터 정본 파일을 유지하세요.

### 7. 개별 도서 ISBN 신청과 바코드 확보

- [ ] 발행 전에 [개별도서 ISBN을 신청](https://www.nl.go.kr/seoji/contents/S30201000000.do)합니다.
- [ ] 종이책과 전자책, 서로 다른 언어판·판형·판본의 ISBN을 임의로 재사용하지 않습니다.
- [ ] 처리 결과에서 승인된 도서정보와 ISBN을 확인합니다.
- [ ] 국립중앙도서관 시스템에서 공식 바코드를 내려받아 체크숫자와 부가기호를 확인합니다.
- [ ] ISBN을 판권면에, 바코드·정가를 뒤표지의 조용한 영역에 배치합니다.

국립중앙도서관은 발행자번호를 받은 발행자가 발간 전에 ISBN을 신청하도록 안내하며, 온라인 신청 처리기한은 신청 다음 날부터 업무일 기준 3일 이내입니다. ISBN은 저작권 등록번호가 아니며 책의 식별자입니다.

### 8. 내지·표지·전자책 제작

- [ ] 최종 목차와 원고를 동결한 뒤 맞춤법, 사실, 인용, 개인정보를 검수합니다.
- [ ] PDF 내지를 실제 판형으로 렌더하고 글꼴 포함, 페이지 수, 홀짝 페이지와 빈 페이지를 확인합니다.
- [ ] 최종 내지 쪽수와 선택한 종이로 책등을 계산한 뒤 펼침표지를 만듭니다.
- [ ] 도련, 접지, 날개, 바코드 여백과 표지 색상모드를 POD 규격에 맞춥니다.
- [ ] EPUB은 별도 렌더해 목차, 표, 이미지, 링크, 작은 화면 재배치를 확인합니다.
- [ ] 생성형 AI를 원고나 표지에 사용했다면 이용 플랫폼의 표시 기준과 권리 조건을 확인합니다.

### 9. 인쇄 전 교정본과 권리·품질 최종 검수

- [ ] PDF의 대표 페이지와 의심 페이지를 이미지로 변환해 육안 검사합니다.
- [ ] ISBN·정가·발행처·발행일이 판권면, 표지와 등록 정보에서 일치하는지 확인합니다.
- [ ] 바코드가 실제로 판독되는지 확인합니다.
- [ ] 흑백 본문의 그래프·사진·가는 선과 작은 글자가 인쇄 가능한지 확인합니다.
- [ ] 샘플 인쇄 또는 저자용 1부를 주문해 재단, 책등, 제본, 색상과 오탈자를 확인합니다.

### 10. 교보문고 파트너 가입

- [ ] [교보문고 파트너시스템](https://partner.kyobobook.co.kr/dpart/pcc/members)에서 개인사업자 또는 법인사업자 유형으로 가입합니다.
- [ ] 사업자등록증, 정산계좌와 계약 단계에서 요구하는 최신 서류를 제출합니다.
- [ ] 계약 주체, 출판사명, 예금주와 계산서 발행 주체가 일치하는지 확인합니다.

교보문고는 사업자 파트너에게 바로출판 POD와 전자책 서비스를 제공하고, 개인저자 가입은 POD 전용이라고 안내합니다. 자기 출판사의 전자책까지 등록하려면 사업자 파트너 유형을 사용해야 합니다.

### 11. 교보문고 바로출판 POD 등록

- [ ] 파트너시스템의 POD 등록에서 판형·종이·제본·표지 사양을 선택합니다.
- [ ] 검증된 내지 PDF와 최종 펼침표지 PDF를 업로드합니다.
- [ ] ISBN, 책 소개, 저자 소개, 목차, 분야, 정가와 발행일을 메타데이터 정본에서 옮깁니다.
- [ ] AI를 원고 또는 표지에 사용했다면 등록 화면의 **AI 활용 여부**를 사실대로 선택합니다.
- [ ] 미리보기와 자동검사 결과를 확인한 뒤 판매 신청합니다.
- [ ] 승인 반려 시 반려 사유만 수정하고, 소스·PDF·표지를 함께 버전 관리해 재신청합니다.

[교보문고 바로출판 POD 안내](https://mobile.kyobobook.co.kr/partners/pod-new-guide)는 사업자 파트너 가입, 본문·표지 PDF 업로드, 판매 신청, 승인, 주문 제작·배송, 정산 순서를 안내합니다. 현재 안내상 판매 신청 뒤 승인 메일은 통상 2~3영업일 이내지만 보완 여부에 따라 달라질 수 있습니다.

### 12. 전자책 등록 — 선택

- [ ] 종이책과 별도의 전자책 ISBN과 판권 정보를 사용합니다.
- [ ] EPUB의 접근성, 목차, 표지, 이미지 크기, 링크와 재배치를 검사합니다.
- [ ] DRM, 판매지역, 가격, 정산조건과 파일 교체 정책을 확인합니다.
- [ ] 교보문고 외 유통사를 병행하면 독점 여부와 메타데이터 일치를 확인합니다.

### 13. 판매 개시와 직접 판매 분기

- [ ] 교보문고 판매승인 메일 뒤 실제 상품페이지의 표지·제목·ISBN·정가를 확인합니다.
- [ ] 저자용 1부를 주문하고 배송된 실물을 최종 검사합니다.
- [ ] 상품 URL, 출간일, 홍보문과 수정 가능한 오류 목록을 기록합니다.
- [ ] 자체 쇼핑몰, SNS 주문 또는 계좌이체로 직접 판매한다면 전자상거래 소매업, 통신판매업 신고, 이용약관, 개인정보처리방침, 청약철회·환불과 현금영수증 의무를 별도로 확인합니다.

교보문고 안에서만 주문·결제·배송하는 경우와 출판사가 직접 소비자 주문을 받는 경우의 의무가 같지 않을 수 있습니다. 직접 판매를 시작하기 전에 정부24, 관할 지자체와 국세청에 현재 요건을 확인하세요.

### 14. 전자계산서·전자세금계산서와 교보 정산

- [ ] 홈택스에서 전자 발급에 사용할 공동인증서, 세무서 보안카드 또는 지원되는 인증수단을 준비합니다.
- [ ] **도서 면세매출은 전자계산서**, 과세 재화·용역은 **전자세금계산서**라는 차이를 확인합니다.
- [ ] 교보문고 파트너시스템에서 월 판매·반품·정산내역을 대조합니다.
- [ ] 교보문고가 제공하는 역발행 계산서가 있으면 공급가액·작성일자·사업자정보를 확인한 뒤 승인합니다.
- [ ] 직접 발행하는 경우에도 계약상 발행기한과 홈택스 전송 여부를 확인합니다.
- [ ] 입금액, 계산서 공급가액, 판매보고서가 일치하는지 월별로 대사합니다.

국세청은 면세거래에 발급하는 전자 문서를 **전자계산서**라고 설명합니다. 따라서 출판사가 책 판매 정산에 무조건 `전자세금계산서`를 발급한다고 쓰면 틀릴 수 있습니다. 교보문고도 출판사 정산에 계산서 직접 발행 또는 무료 역발행 계산서 승인을 안내합니다. 전자 발급 의무 기준은 매출 규모와 사업자 유형에 따라 바뀔 수 있으므로 매년 국세청의 [전자(세금)계산서 안내](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7786&mi=2443)를 확인하세요.

### 15. 국립중앙도서관 납본

- [ ] 책의 실제 발행일을 기록합니다.
- [ ] 발행·제작일부터 30일 이내에 종이책 2부와 필요한 서류를 국립중앙도서관에 납본합니다.
- [ ] 전자책을 발행했다면 온라인 자료 납본 절차도 별도로 진행합니다.
- [ ] 납본 접수·보상 관련 기록과 배송증빙을 보관합니다.

국립중앙도서관 안내에 따르면 납본은 법정 의무이며 일반 도서와 온라인 자료는 각각 2부를 발행·제작일부터 30일 이내 제출합니다. 최신 주소, 서식과 파일 제출 방식은 [ISBN·ISSN·UCI·납본 시스템](https://www.nl.go.kr/seoji/)에서 확인하세요.

- [ ] 매월 판매·반품·정산·경비와 계산서 수취·발급을 마감합니다.
- [ ] 면세 개인사업자는 다음 해 **2월 10일** 사업장현황신고 대상인지 확인합니다.

국세청은 부가가치세 면세 개인사업자의 사업장현황신고를 원칙적으로 다음 해 2월 10일까지, 개인의 종합소득세 신고·납부를 다음 해 5월 1~31일까지 안내합니다. 정확한 대상과 제출서류는 매년 최신 공지를 확인하세요.

```bash
python ~/.codex/skills/quarto-korean-pod-book/scripts/audit_quarto_book.py /path/to/book
```

필수 절 제목도 함께 검사할 수 있습니다.

```bash
python ~/.codex/skills/quarto-korean-pod-book/scripts/audit_quarto_book.py /path/to/book \
```

이 도구는 `_quarto.yml`에 등록된 장 파일, 중복 제목, 이미지 대체텍스트, 직접 URL이 없는 출처 절을 점검합니다.

```bash
python ~/.codex/skills/quarto-korean-pod-book/scripts/calc_cover_geometry.py \
  --pages 262 \
  --paper-thickness-mm 0.12 \
  --wing-mm 80
```

계산값은 초기 설계용입니다. 최종 책등은 반드시 POD 플랫폼 또는 인쇄소의 종이별 계산값을 우선해야 합니다.
