# 한국어 POD 제작 기준

## 판형과 도련

- A5 완성 크기: 148 × 210mm.
- 재단선까지 배경이나 그림이 닿는 면은 사방 3mm 도련을 더해 154 × 216mm로 만든다.
- 흰 여백만 있는 일반 내지는 플랫폼이 별도 도련을 요구하지 않으면 A5 완성 크기로 제출한다.
- 펼침표지는 바깥 도련, 책날개, 접지 여유, 뒤표지, 책등, 앞표지 순서를 플랫폼 템플릿과 대조한다.

## 책등 계산

백색모조 100g의 초기 추정치는 종이 한 장당 0.12mm를 사용한다.

```text
장수 = ceil(본문 쪽수 / 2)
책등 = ceil(장수 × 0.12mm)
```

실제 종이와 제본의 캘리퍼가 다르므로 유통사 계산값이나 인쇄소 실측값을 최종값으로 사용한다.

## 날개 펼침표지

기본식:

```text
가로 = 앞표지 + 뒤표지 + 책등 + 2×날개 + 2×바깥 도련 + 2×접지 여유
세로 = 완성 높이 + 2×도련
```

A5, 날개 80mm, 도련 3mm, 접지 여유 3mm, 책등 16mm이면 484 × 216mm다.

## 제출 전 확인

- 표지: 컬러, 스노우 250g, 무광 코팅 여부를 주문 정보와 일치시킨다.
- 본문: 흑백, 백색모조 100g 여부를 주문 정보와 일치시킨다.
- 표지 PDF의 MediaBox·BleedBox·TrimBox를 확인한다.
- 바코드는 할당된 종이책 ISBN으로 생성하고 육안과 체크섬을 모두 검사한다.
- 종이책과 전자책 ISBN을 혼용하지 않는다.
- 최종 쪽수가 바뀌면 책등과 펼침표지를 반드시 다시 만든다.
